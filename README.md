![Python](https://img.shields.io/badge/Python-3.x-blue?style=flat-square&logo=python&logoColor=white)
![Status](https://img.shields.io/badge/Status-Concluído-success?style=flat-square)

Um script divertido e minimalista em Python que simula a clássica "Bola 8 Mágica". Faça uma pergunta e deixe o código decidir o seu destino! 

## ✨ Funcionalidades

- **Interação Simples:** Recebe qualquer pergunta digitada pelo usuário.
- **Suspense:** Faz uma pausa dramática de 2 segundos simulando que está "pensando" (via biblioteca `time`).
- **Aleatoriedade:** Retorna uma resposta positiva, negativa ou neutra de forma totalmente randômica (via biblioteca `random`).

## 🚀 Como rodar

1. Certifique-se de ter o **Python** instalado na sua máquina.
2. Salve o arquivo `bola_magica.py`.
3. Abra o terminal na pasta do arquivo e execute:
   ```bash
   python bola_magica.py
